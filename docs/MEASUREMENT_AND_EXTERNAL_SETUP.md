# سنجش رشد و اتصال‌های بیرونی

این سند مرز میان کد آماده‌شده و کارهایی را روشن می‌کند که فقط مالک حساب می‌تواند انجام دهد. هیچ توکن، رمز، کد یک‌بارمصرف یا اطلاعات هویتی نباید در گفت‌وگو یا مخزن ثبت شود.

## وضعیت اتصال‌ها

| بخش                      | وضعیت کد                                          | اقدام مالک                                                                                                      |
| ------------------------ | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| sitemap و robots.txt     | فعال؛ `sitemap-index.xml` در robots معرفی شده است | بعد از تأیید مالکیت، sitemap را در Search Console ثبت کند                                                       |
| Google Search Console    | نیازمند حساب                                      | ورود به Search Console، دریافت TXT تازه، افزودن در DNS و زدن Verify                                             |
| Bing Webmaster Tools     | نیازمند حساب                                      | ورود و افزودن دامنه؛ در صورت امکان پس از تأیید Google از Import استفاده شود                                     |
| IndexNow                 | کلید، فایل عمومی و اسکریپت ارسال آماده است        | ندارد؛ بعد از هر انتشار با `pnpm indexnow:submit` اجرا می‌شود                                                   |
| Cloudflare Web Analytics | اتصال شرطی با متغیر محیطی آماده است               | فعال‌سازی سایت؛ اگر تزریق خودکار Cloudflare روشن است token در کد قرار نگیرد، وگرنه token در محیط ساخت تنظیم شود |
| رویدادهای رفتاری         | نام‌گذاری و data attribute در سایت پیاده شده است  | انتخاب ابزار جمع‌آوری رویداد سفارشی پس از بررسی حریم خصوصی                                                      |
| خطاهای مرورگر            | رویداد بدون متن خطا منتشر می‌شود                  | اتصال به سرویس خطا فقط پس از انتخاب سرویس و بازبینی حریم خصوصی                                                  |

## قرارداد رویدادها

رویدادها اطلاعات فرم، نام مشتری، شماره تماس یا متن خطا را ثبت نمی‌کنند. ویژگی‌های مجاز فقط مسیر صفحه، جایگاه ثابت پیوند، مقصد عمومی و عمق مطالعه هستند.

| رویداد                     | معنا                                                   |
| -------------------------- | ------------------------------------------------------ |
| `guide_open`               | ورود به یک راهنمای جامع از کارت موضوعی                 |
| `guide_reading_started`    | دیده‌شدن بدنهٔ راهنمای جامع                            |
| `guide_to_metrazh`         | رفتن از راهنمای جامع به صفحهٔ متراژ                    |
| `article_open`             | ورود به مقاله از یک کارت محتوایی                       |
| `article_reading_started`  | دیده‌شدن بدنهٔ مقاله                                   |
| `article_to_guide`         | رفتن از مقالهٔ جزئی به راهنمای جامع مرتبط              |
| `scroll_depth`             | رسیدن به عمق ۵۰ یا ۹۰ درصد صفحه                        |
| `article_to_metrazh`       | رفتن از مقاله به صفحهٔ متراژ                           |
| `metrazh_page_view`        | دیده‌شدن بخش اصلی صفحهٔ متراژ                          |
| `metrazh_screenshots_open` | انتخاب تور تصویری محصول                                |
| `metrazh_quick_start_view` | دیده‌شدن بخش اولین ۱۰ دقیقه                            |
| `metrazh_scenarios_view`   | دیده‌شدن سناریوهای واقعی استفاده                       |
| `metrazh_bazaar_click`     | خروج به صفحهٔ رسمی کافه‌بازار                          |
| `client_error`             | رخداد خطای جاوااسکریپت بدون ذخیرهٔ پیام یا دادهٔ کاربر |

قیف پایه برای گزارش هفتگی:

`ورودی جست‌وجو → راهنمای جامع یا مقاله → صفحهٔ متراژ → کلیک کافه‌بازار`

## داشبورد هفتگی

هر هفته یک ردیف با این ستون‌ها ثبت شود:

| بازه    | ورودی جست‌وجو | شروع مطالعه | رفتن به متراژ | کلیک بازار | نرخ مقاله به بازار | LCP P75 | INP P75 | CLS P75 | خطا | بهترین مطلب      | اقدام هفتهٔ بعد    |
| ------- | ------------: | ----------: | ------------: | ---------: | -----------------: | ------: | ------: | ------: | --: | ---------------- | ------------------ |
| خط مبنا |             — |           — |             — |          — |                  — |       — |       — |       — |   — | پس از اتصال داده | پس از یک هفته داده |

تا زمانی که دادهٔ واقعی جمع نشده، هیچ درصد یا هدف عددی ساخته نمی‌شود.

## آزمایش متن اقدام اصلی

- مبنای فعلی: «دریافت مستقیم از کافه‌بازار»
- گزینهٔ بعدی: «نصب متراژ و شروع اولین فایل»

آزمایش فقط وقتی شروع می‌شود که ابزار سنجش فعال، حجم داده کافی و یک معیار موفقیت مشخص وجود داشته باشد. پیش از آن تغییر تصادفی متن فقط نتیجه را مبهم می‌کند.

## ترتیب اقدام مالک

1. ورود شخصی به Search Console و تأیید DNS با TXT تازه.
2. ثبت `https://mahsai.ir/sitemap-index.xml`.
3. ورود به Bing Webmaster Tools و افزودن دامنه.
4. فعال‌سازی Cloudflare Web Analytics و دریافت snippet یا token عمومی سایت.
5. ارسال token از مسیر امن تنظیمات ساخت؛ نه در گفت‌وگو و نه در commit.
6. به‌روزرسانی صفحهٔ حریم خصوصی هم‌زمان با فعال‌شدن سنجش.
