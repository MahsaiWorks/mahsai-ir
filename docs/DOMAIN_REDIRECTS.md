# انتقال مسیرهای قدیمی دامنه

تاریخ بررسی: ۲۸ مرداد ۱۴۰۵

تمام مسیرهای عمومی قدیمی زیر `/ai/` از تاریخچهٔ نسخهٔ قبلی استخراج و در ساخت استاتیک به `/apps/` هدایت شده‌اند. sitemap نیز هیچ مسیر `/ai/` را منتشر نمی‌کند.

## وضعیت فعال Cloudflare

`Astro.redirect(..., 301)` در خروجی استاتیک صفحهٔ fallback می‌سازد، اما GitHub Pages پاسخ HTTP واقعی ۳۰۱ صادر نمی‌کند. به همین دلیل Redirect Rule زیر در لایهٔ دامنهٔ Cloudflare فعال شد:

```text
اگر مسیر با /ai/ شروع می‌شود
انتقال به https://mahsai.ir/apps/
نوع انتقال: 301 Permanent
حفظ query string: بله
```

کنترل زندهٔ زیر پس از فعال‌سازی اجرا شد:

```text
curl -I https://mahsai.ir/ai/
curl -I https://mahsai.ir/ai/tools/chatgpt/
```

نتیجهٔ تأییدشده: وضعیت ۳۰۱ و هدر `Location: https://mahsai.ir/apps/?source=qa` برای درخواست آزمایشی دارای query string. بنابراین هم انتقال دائمی و هم حفظ query string فعال است.

صفحه‌های fallback استاتیک همچنان نگهداری می‌شوند تا اگر پروکسی موقتاً کنار گذاشته شد، کاربر به محتوای حذف‌شده نرسد. قاعدهٔ فعال Cloudflare منبع پاسخ واقعی ۳۰۱ است.
