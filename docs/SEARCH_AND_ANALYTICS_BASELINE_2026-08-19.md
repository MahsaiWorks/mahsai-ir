# خط مبنای Search Console و Cloudflare Web Analytics

تاریخ مشاهده: ۲۸ مرداد ۱۴۰۵ / ۱۹ اوت ۲۰۲۶

این سند فقط دادهٔ مشاهده‌شده را ثبت می‌کند. حجم نمونه هنوز برای ادعای رشد، تعیین هدف عددی یا بازنویسی گستردهٔ محتوا کافی نیست.

## Google Search Console

- Property دامنهٔ `mahsai.ir` تأیید و قابل استفاده است.
- sitemap رسمی `https://mahsai.ir/sitemap-index.xml` با وضعیت `Success` ثبت شده است.
- sitemap تعداد ۵۵ صفحه را کشف کرده است.
- گزارش عملکرد بازهٔ ۳ماهه تا ۱۶ اوت: ۳ کلیک، ۲۰ نمایش، CTR برابر ۱۵٪ و جایگاه میانگین ۳٫۸.
- تنها عبارت قابل مشاهده در جدول پرسش‌ها «محسای» با ۲ نمایش و بدون کلیک بود؛ از یک عبارت و دو نمایش نتیجهٔ محتوایی قطعی گرفته نمی‌شود.

### صفحه‌های قابل مشاهده در گزارش عملکرد

مسیرهای قدیمی `/ai/` از sitemap حذف شده‌اند و به `/apps/` انتقال دائمی دارند. نمایش باقی‌ماندهٔ آن‌ها دادهٔ تاریخی گوگل است، نه بازگشت محور هوش مصنوعی به سایت.

### وضعیت ایندکس

- ۵۵ صفحه ایندکس‌شده.
- ۷ صفحه ایندکس‌نشده: ۴ انتقال، ۲ صفحه crawlشده و فعلاً ایندکس‌نشده، و ۱ صفحه کشف‌شده و فعلاً ایندکس‌نشده.
- انتقال‌های مسیر قدیمی رفتار مورد انتظارند.
- یکی از دو صفحهٔ crawlشده `/articles/secure-real-estate-data/` است؛ اعتبارسنجی مجدد در ۲۸ مرداد آغاز شده و باید بدون ارسال تکراری درخواست، نتیجهٔ آن پیگیری شود.
- صفحهٔ کشف‌شدهٔ ایندکس‌نشده یک مسیر قدیمی `/ai/` است و نیازمند تولید محتوای تازه نیست.

## Cloudflare Web Analytics

- ابزار حدود دو ساعت پیش از مشاهده فعال شده بود.
- ۷ بازدید و ۷ نمایش صفحه در ۲۴ ساعت نخست ثبت شد.
- زمان بارگذاری گزارش‌شده ۱٬۱۹۱ میلی‌ثانیه بود.
- پنل صریحاً اعلام کرد داده برای گزارش جزئی Web Analytics و Core Web Vitals هنوز کافی نیست.

## تصمیم این چرخه

1. sitemap یا ساختار صفحه‌ها تغییر نمی‌کند؛ ثبت و پوشش فعلی سالم است.
2. عنوان مقاله‌ها با این نمونهٔ کوچک بازنویسی نمی‌شود.
3. پیام صفحهٔ خانه مشخص‌تر می‌شود و اقدام اصلی مستقیماً نصب متراژ از کافه‌بازار خواهد بود.
4. املای رسمی فارسی «مهسای» به دادهٔ ساختاریافتهٔ برند اضافه می‌شود؛ املای نادرست جست‌وجوشده وارد متن سایت نمی‌شود.
5. داده در ۴ شهریور ۱۴۰۵ دوباره خوانده می‌شود؛ سپس پرسش، صفحه و مسیر دارای نمایش کافی برای آزمایش انتخاب خواهد شد.

## گام بیرونی باقی‌مانده

Bing Webmaster Tools هنوز وارد حساب نشده است. افزودن دامنه به ورود Microsoft یا Google و پذیرش سطح دسترسی همان سرویس نیاز دارد و بدون ورود مالک انجام نمی‌شود.
