# گزارش هفتگی قیف MAHSAI

نسخهٔ قالب: ۱ — شروع ثبت: ۳۰ مرداد ۱۴۰۵ / ۲۱ اوت ۲۰۲۶

این گزارش هر هفته با یک ردیف تازه ادامه پیدا می‌کند. عدد ناموجود با «—» ثبت می‌شود و هرگز با صفر جایگزین نمی‌شود. تعریف همهٔ ستون‌ها در `MEASUREMENT_DICTIONARY.md` ثابت است.

## جدول ثابت

| پایان بازه    | کلیک جست‌وجو | نمایش جست‌وجو | شروع مطالعه | رفتن به متراژ | کلیک بازار | نصب قابل انتساب | نرخ مطالعه تا متراژ | نرخ بازار تا نصب | تصمیم هفته                                                   |
| ------------- | -----------: | ------------: | ----------: | ------------: | ---------: | --------------: | ------------------: | ---------------: | ------------------------------------------------------------ |
| ۳۰ مرداد ۱۴۰۵ |            ۳ |            ۳۴ |           — |             — |          — |               ۰ |                   — |                — | ابتدا سنجش کامل شود؛ تیتر، تصویر و دکمه هم‌زمان تغییر نکنند. |

سه کلیک Search Console مربوط به بازهٔ قابل مشاهدهٔ ۳۱ ژوئیه تا ۱۸ اوت است. سنجش رفتاری سایت از ۳۰ مرداد آغاز می‌شود؛ بنابراین خانه‌های پیش از آن «—» هستند. D1 انتساب نصب در زمان ثبت خط مبنا هیچ ردیف واقعی نداشت.

## منابع هر ستون

1. کلیک و نمایش جست‌وجو: Search Console با بازهٔ دقیق گزارش.
2. شروع مطالعه، رفتن به متراژ و کلیک بازار: View خصوصی `mahsai_site_event_daily_summary` در D1 با نام `mahsai-metrics`.
3. نصب قابل انتساب: View خصوصی `metrazh_install_attribution_daily_summary` در D1 با نام `mahsai-metrazh-attribution`.
4. نرخ فقط وقتی محاسبه می‌شود که صورت و مخرج، بازه و برچسب قابل تطبیق داشته باشند.

## پرس‌وجوی رویدادهای سایت

```sql
SELECT day, name, path, location, events
FROM mahsai_site_event_daily_summary
WHERE day BETWEEN 'YYYY-MM-DD' AND 'YYYY-MM-DD'
ORDER BY day, name, path, location;
```

## پرس‌وجوی نصب

```sql
SELECT day, campaign, installs
FROM metrazh_install_attribution_daily_summary
WHERE day BETWEEN 'YYYY-MM-DD' AND 'YYYY-MM-DD'
ORDER BY day, campaign;
```

## قاعدهٔ تصمیم

- پیش از شروع آزمایش، فقط یک متغیر و یک معیار موفقیت ثبت می‌شود.
- تغییر فنی، دسترس‌پذیری، حریم خصوصی و ادعای نادرست منتظر نمونه نمی‌ماند.
- برای نتیجهٔ محتوایی یا تبدیل، حداقل‌های سند `MEASUREMENT_DICTIONARY.md` رعایت می‌شوند.
