# فرهنگ معیارهای MAHSAI

نسخه: ۱ — ۳۰ مرداد ۱۴۰۵ / ۲۱ اوت ۲۰۲۶

این سند مرجع ثابت سنجش است. در گزارش، مقاله، تصمیم طراحی یا گفت‌وگو از واژه‌های زیر فقط با همین معنا استفاده می‌شود.

## معیارهای اصلی قیف

| معیار            | تعریف عملیاتی                                                                                                                               | منبع قطعی                  | چیزی که این معیار ثابت نمی‌کند                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | -------------------------------------------------------------------- |
| نمایش در جست‌وجو | یک بار نمایش نتیجهٔ `mahsai.ir` در نتایج گوگل طبق تعریف Search Console                                                                      | Google Search Console      | دیده‌شدن واقعی متن صفحه یا شناخت برند                                |
| ورودی جست‌وجو    | یک کلیک ثبت‌شده از نتیجهٔ گوگل به یکی از صفحه‌های سایت                                                                                      | Google Search Console      | بازدید یکتا در همهٔ کانال‌ها                                         |
| بازدید           | یک Visit طبق تعریف Cloudflare Web Analytics؛ با نمایش صفحه جمع زده نمی‌شود                                                                  | Cloudflare Web Analytics   | هویت کاربر یا مطالعهٔ محتوا                                          |
| شروع مطالعه      | نخستین رویداد `article_reading_started` یا `guide_reading_started` پس از دیده‌شدن بدنهٔ همان مطلب                                           | جمع‌کنندهٔ رویداد MAHSAI   | خواندن کامل یا مفیدبودن مطلب                                         |
| رفتن به متراژ    | رویداد `article_to_metrazh` یا `guide_to_metrazh` از داخل یک محتوای مشخص                                                                    | جمع‌کنندهٔ رویداد MAHSAI   | بازشدن بازار یا نصب برنامه                                           |
| کلیک بازار       | رویداد `metrazh_bazaar_click` روی پیوند رسمی کافه‌بازار                                                                                     | جمع‌کنندهٔ رویداد MAHSAI   | کامل‌شدن نصب                                                         |
| نصب قابل انتساب  | دریافت یک `event_id` تازه از قرارداد `metrazh_install_attribution_v1` پس از آن‌که نسخهٔ بازار اطلاعات نصب را در اجرای برنامه ارسال کرده است | اپ متراژ و endpoint انتساب | تعداد کل نصب بازار، کاربر یکتا در همهٔ دستگاه‌ها یا استفادهٔ بلندمدت |

«نصب قابل انتساب» عمداً با «کلیک نصب در بازار» یکی نیست. ثبت این رویداد یعنی برنامه پس از نصب دست‌کم یک بار اجرا شده و اطلاعات انتساب معتبر بازار به endpoint رسیده است.

## قواعد شمارش

1. اعداد Search Console و Cloudflare از پنل رسمی همان سرویس خوانده می‌شوند و با رویدادهای داخلی جمع نمی‌شوند.
2. شروع مطالعه در هر بار بارگذاری صفحه فقط یک بار برای همان مطلب ثبت می‌شود.
3. رفتن به متراژ فقط از پیوندی شمرده می‌شود که نام رویداد ثابت و مسیر مبدأ معتبر داشته باشد.
4. کلیک بازار کلیک روی مقصد رسمی `cafebazaar.ir/app/ir.fileryar.amlakyar` است؛ پارامتر کامل مقصد ذخیره نمی‌شود.
5. `event_id` نصب کلید یکتاست. ارسال دوبارهٔ همان شناسه پاسخ موفقِ تکراری می‌گیرد، اما دوباره شمرده نمی‌شود.
6. روز و ساعت گزارش با تقویم میلادی و منطقهٔ زمانی `Asia/Tehran` ذخیره می‌شود؛ نمایش تاریخ شمسی فقط در لایهٔ گزارش انجام می‌شود.
7. ربات‌ها از گزارش Cloudflare حذف می‌شوند. رویدادهای داخلی نیز با اعتبارسنجی، محدودیت نرخ و فهرست مجاز کنترل می‌شوند، اما «انسان یکتا» نامیده نمی‌شوند.

## نرخ‌های مجاز

| نام نرخ             | فرمول                                              |
| ------------------- | -------------------------------------------------- |
| نرخ شروع مطالعه     | شروع مطالعه ÷ ورودی همان محتوای قابل اندازه‌گیری   |
| نرخ رفتن به متراژ   | رفتن به متراژ ÷ شروع مطالعه                        |
| نرخ کلیک بازار      | کلیک بازار ÷ دیده‌شدن صفحهٔ متراژ                  |
| نرخ نصب قابل انتساب | نصب قابل انتساب ÷ کلیک بازارِ کمپین‌های قابل تطبیق |

اگر صورت یا مخرج از دو سیستم با بازهٔ زمانی یا برچسب متفاوت آمده باشد، نرخ ساخته نمی‌شود و مقدار «دادهٔ قابل تطبیق نداریم» گزارش می‌شود.

## داده‌های مجاز و ممنوع

رویداد سایت فقط این چهار دسته را می‌پذیرد: نام رویداد از فهرست ثابت، مسیر پاک‌سازی‌شده، جایگاه ثابت و ساعت دریافت به وقت تهران. دادهٔ فرم، متن آزاد، مقصد کامل، Query String، IP خام و User-Agent ذخیره نمی‌شود.

رویداد نصب فقط فیلدهای قرارداد نسخهٔ ۱ را می‌پذیرد: `schema`، `event_id`، `campaign` پاک‌سازی‌شده، دو زمان بازار، `app_version` و `app_build`. شماره تلفن، پروفایل، اطلاعات ملک یا مشتری، Android ID و شناسهٔ تبلیغاتی ممنوع‌اند؛ وجود فیلد اضافه باعث رد درخواست می‌شود.

دادهٔ خام حداقلی حداکثر ۹۰ روز نگه داشته می‌شود. گزارش خلاصه خصوصی است و پاسخ آن با `Cache-Control: no-store` ارائه می‌شود.

## قاعدهٔ تصمیم و آزمایش

- هر آزمایش فقط یک متغیر دارد: تیتر، تصویر یا دکمه؛ نه چند مورد با هم.
- معیار موفقیت و بازهٔ آزمایش پیش از تغییر ثبت می‌شود.
- آزمایش کمتر از ۱۴ روز یا کمتر از ۱۰۰ مشاهده برای هر گزینه نتیجهٔ قطعی نامیده نمی‌شود.
- برای تصمیم تبدیل، هر گزینه باید حداقل ۲۰ رخدادِ معیار هدف داشته باشد؛ در غیر این صورت نتیجه «نامشخص» است.
- خطای فنی، ادعای نادرست، مشکل دسترس‌پذیری یا حریم خصوصی بدون انتظار برای نمونه اصلاح می‌شود.
