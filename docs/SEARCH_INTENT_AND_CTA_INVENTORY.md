## مرز صفحه‌های نزدیک به هم

- `متراژ` صفحهٔ شناخت محصول است؛ `دانلود` فقط برای نصب، `وضعیت` فقط برای نسخهٔ فعلی و `تاریخچه` فقط برای تغییرات نسخه‌هاست.
- `بهترین نرم‌افزار مشاور املاک` صفحهٔ انتخاب عمومی است و نباید با عبارت برند «متراژ» رقابت کند.
- صفحهٔ موضوع، راه ورودی به چند مطلب است؛ راهنمای جامع یک فرایند کامل را پوشش می‌دهد و مقاله فقط یک سؤال دقیق را جواب می‌دهد.
- `ابزارها` برای استفادهٔ تعاملی است؛ `چک‌لیست‌ها` برای ذخیره یا چاپ و `آکادمی` برای یادگیری مرحله‌ای است.

## کنترل اجرا

- همهٔ ۴۳ صفحه canonical خودارجاع دارند.
- نبود canonical، canonical تکراری یا canonical ناسازگار با مسیر باعث شکست ممیزی انتشار می‌شود.
- مسیرهای قدیمی `/ai/` در sitemap نیستند و جزو این فهرست به حساب نمی‌آیند.
