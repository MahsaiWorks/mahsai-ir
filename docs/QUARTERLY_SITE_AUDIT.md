# بازبینی کامل ۹۰ روزهٔ سایت

## تجربه و برند

- صفحه‌های خانه، متراژ، آکادمی، مقاله و پشتیبانی در ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل؛
- لوگوی واقعی MAHSAI و نشان رسمی متراژ؛
- نبود محصول منتشرنشده یا تصویر قدیمی؛
- خوانایی فارسی، فضای خالی، سلسله‌مراتب تیتر و کیفیت تصویر.

## محصول و اعتماد

- تطبیق نسخه، تاریخ و پیوند بازار؛
- تست نصب، پشتیبانی، حریم خصوصی و تاریخچهٔ نسخه؛
- بررسی نظرها و تجربه‌های واقعی با رضایت؛
- بازبینی حقوقی مطالب حساس و شرایط تجاری.

## سئو و محتوا

- Search Console: query، page، CTR، indexing و Core Web Vitals؛
- گزارش مطلب قدیمی، لینک شکسته و صفحهٔ بدون پیوند؛
- مقایسهٔ نیازهای جست‌وجوی تازه و صفحه‌های مفید رقیب؛
- حذف هم‌پوشانی موضوعی و بهبود پاسخ ناقص؛
- تصمیم فصل بعد بر اساس دفتر داده، نه تعداد صفحه.

## فنی و امنیت

- build، type check، static audit، Axe، reflow و Lighthouse؛
- سرآیندهای امنیتی، TLS، security.txt، SPF، DKIM و DMARC؛
- بودجهٔ HTML/CSS/JS/font/image؛
- کنترل redirectهای قدیمی و canonical/sitemap؛
- بازیابی از نسخهٔ پشتیبان و مرور دسترسی حساب‌ها.

Workflow فصلی این تست‌های خودکار را اجرا و یک issue برای بخش‌های انسانی باز می‌کند. سبزشدن تست خودکار جای تست خوانندهٔ صفحه، بازبینی حقوقی یا دادهٔ Search Console را نمی‌گیرد.
