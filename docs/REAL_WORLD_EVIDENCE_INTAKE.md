# الگوی جمع‌آوری تجربهٔ واقعی و مصاحبهٔ مشاور املاک

هدف این فایل آماده‌کردن گام‌های ۴۶ و ۵۰ است. تا پیش از دریافت تجربهٔ واقعی، هیچ نقل‌قول، نام، نتیجه یا سناریویی به‌عنوان تجربهٔ کاربر منتشر نمی‌شود.

## مرزهای حریم خصوصی

- نام، تلفن، نشانی دقیق، کد ملی، تصویر مدرک و اطلاعات مالک یا متقاضی دریافت نشود.
- فایل یا تصویر فقط پس از حذف دادهٔ شخصی پذیرفته شود.
- انتشار نقل‌قول نیازمند اجازهٔ روشن برای همان متن نهایی است.
- رضایت به استفاده از محصول، رضایت به انتشار نام یا تصویر نیست.
- شرکت‌کننده هر زمان می‌تواند پیش از انتشار، اجازه را پس بگیرد.

## پنج مصاحبهٔ لازم برای هر خوشهٔ تازه

برای هر نفر فقط نقش کلی و اندازهٔ کار ثبت شود؛ مثل «مشاور مستقل با حجم فایل متوسط».

1. آخرین بار این کار را دقیقاً چه زمانی انجام دادید؟
2. از کجا شروع کردید و چه ابزارهایی کنار هم داشتید؟
3. کدام بخش بیشتر وقت گرفت یا باعث خطا شد؟
4. چه اطلاعاتی کم بود و مجبور شدید دوباره تماس بگیرید؟
5. بعد از پایان کار، اقدام بعدی را کجا ثبت کردید؟
6. اگر ابزار فعلی حذف شود، چه چیزی بیش از همه آسیب می‌بیند؟
7. چه اصطلاحی را خودتان برای این مسئله به کار می‌برید؟
8. چه راه‌حلی را امتحان کردید که جواب نداد و چرا؟

## قالب نمونهٔ ناشناس

| فیلد         | مقدار مجاز                                        |
| ------------ | ------------------------------------------------- |
| نقش          | مشاور مستقل، مسئول فایل، مدیر دفتر یا مشاور پروژه |
| اندازهٔ کار  | کم، متوسط یا زیاد؛ بدون عدد ساختگی                |
| مسئله        | یک اتفاق واقعی و مشخص                             |
| روش قبلی     | ابزار و مراحل واقعی                               |
| نقطهٔ اصطکاک | زمان، خطا، دوباره‌کاری یا ابهام                   |
| روش تازه     | تغییری که واقعاً اجرا شده                         |
| نتیجه        | مشاهدهٔ کیفی یا عدد مستند و قابل اثبات            |
| اجازه        | متن نهایی تأییدشده، محدودهٔ انتشار و تاریخ        |

## وضعیت فعلی

- مصاحبهٔ ثبت‌شده: صفر
- نمونهٔ واقعی آمادهٔ انتشار: صفر
- نقل‌قول دارای اجازه: صفر

این صفرها گیت داده‌اند، نه شکست اجرا. قالب آماده است و انتشار تا رسیدن مدرک متوقف می‌ماند.
