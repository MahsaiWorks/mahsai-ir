هوش مصنوعی آفلاین یعنی بخشی از کار روی کامپیوتر خودتان انجام شود. این برای یادگیری و بعضی فایل‌های خصوصی جذاب است؛ ولی یک نکته را از اول بدانید: «محلی» همیشه یعنی «سبک و کاملاً خصوصی» نیست. مدل‌ها می‌توانند فضای زیادی بگیرند و سرعتشان به سخت‌افزار شما بستگی دارد.

ما فایل نصب را روی MAHSAI بازنشر نمی‌کنیم. لینک‌ها مستقیم به صفحهٔ رسمی می‌روند تا نسخه و هشدار تازه را همان‌جا ببینید.

## Ollama و LM Studio چه تفاوتی دارند؟

Ollama برای اجرای مدل‌ها از خط فرمان و استفاده از API محلی مسیر ساده‌ای فراهم می‌کند. مستندات رسمی آن نسخه‌های macOS، Windows و Linux را پوشش می‌دهد. در ویندوز، برنامه در پس‌زمینه اجرا می‌شود و API محلی به‌طور پیش‌فرض روی `localhost:11434` در دسترس است.

LM Studio یک رابط گرافیکی برای جست‌وجو، دانلود، مدیریت و گفت‌وگو با مدل‌های محلی دارد و می‌تواند یک API سازگار با الگوی OpenAI ارائه کند. مستندات رسمی آن از Windows، macOS و Linux نام می‌برد و می‌گوید بعد از دریافت فایل مدل، برنامه می‌تواند کاملاً آفلاین کار کند.

| اگر این را می‌خواهید                       | نقطهٔ شروع مناسب‌تر              |
| ------------------------------------------ | -------------------------------- |
| رابط گرافیکی و مدیریت مدل بدون خط فرمان    | LM Studio                        |
| استفاده در اسکریپت، ترمینال یا ابزار توسعه | Ollama                           |
| آزمایش سادهٔ چند مدل روی یک سیستم          | هر دو؛ فقط یکی را ابتدا نصب کنید |

این جدول حکم قطعی نیست. هدفش کم‌کردن انتخاب‌های شروع است.

## بررسی سخت‌افزار قبل از دانلود

### Ollama در ویندوز

راهنمای رسمی Ollama در تاریخ بررسی این صفحه، Windows 10 نسخهٔ 22H2 یا جدیدتر را ذکر می‌کند. برای نصب خود برنامه دست‌کم ۴ گیگابایت فضا لازم است؛ فایل مدل‌ها می‌تواند از ده‌ها تا صدها گیگابایت فضا بگیرد. پشتیبانی و درایور GPU به نوع کارت وابسته است، پس جزئیات همان صفحهٔ رسمی را پیش از نصب بخوانید.

### LM Studio در ویندوز

طبق مستندات رسمی، نسخه‌های x64 و ARM ویندوز پشتیبانی می‌شوند. برای x64 پشتیبانی پردازنده از AVX2 لازم است. ۱۶ گیگابایت رم و حداقل ۴ گیگابایت VRAM اختصاصی توصیه شده است. «توصیه‌شده» با «تضمین اجرای هر مدل» فرق دارد؛ مدل‌های بزرگ‌تر حافظهٔ بیشتری می‌خواهند.

اگر سیستم شما ۸ گیگابایت رم دارد، انتظار واقع‌بینانه داشته باشید: مدل کوچک، زمینهٔ کوتاه و سرعت کمتر. ابتدا مشخصات دقیق رایانه و حجم مدل را بررسی کنید.

## مسیر نصب امن

1. از اطلاعات مهم نسخهٔ پشتیبان داشته باشید و Windows Defender را خاموش نکنید.
2. فقط از [دانلود رسمی Ollama](https://ollama.com/download) یا [دانلود رسمی LM Studio](https://lmstudio.ai/download) استفاده کنید.
3. پیش از اجرا، نام دامنه و امضای ناشر فایل را بررسی کنید.
4. با یک مدل کوچک و شناخته‌شده شروع کنید؛ صفحهٔ مجوز مدل را هم بخوانید.
5. ابتدا یک پرسش عمومی و غیرحساس آزمایش کنید.
6. مصرف RAM، GPU و فضای دیسک را در Task Manager ببینید.

لینک دانلود در سایت MAHSAI همیشه به منبع رسمی می‌رود. اگر یک صفحهٔ ثالث نسخه‌ای «سریع‌تر» یا «کرک‌شده» پیشنهاد کرد، از آن استفاده نکنید.

## آزمایش آفلاین‌بودن

وجود مدل روی دستگاه به‌تنهایی ثابت نمی‌کند کل جریان شما آفلاین است. برای یک بررسی ساده:

1. فایل مدل موردنیاز را در حالت آنلاین و از منبع رسمی دریافت کنید.
2. برنامه را ببندید و دوباره باز کنید تا مطمئن شوید مدل درست بارگذاری می‌شود.
3. اتصال شبکه را موقتاً از تنظیمات ویندوز قطع کنید.
4. همان پرسش آزمایشی را دوباره اجرا کنید.
5. اگر از افزونه، MCP، جست‌وجوی وب یا API خارجی استفاده می‌کنید، آن بخش‌ها را جداگانه بررسی کنید.

آفلاین‌بودن پاسخ مدل به این معنا نیست که فایل شما بی‌خطر یا خروجی مدل درست است. کنترل دسترسی ویندوز، رمزگذاری دیسک، نسخهٔ پشتیبان و بررسی انسانی همچنان لازم‌اند.

## انتخاب اندازهٔ مدل بدون حدس

نام مدل به‌تنهایی برای تشخیص مصرف حافظه کافی نیست. به این موارد نگاه کنید:

- حجم فایل دقیق نسخه‌ای که دانلود می‌کنید؛
- نوع کوانتیزه‌سازی؛
- طول زمینه‌ای که واقعاً نیاز دارید؛
- مقدار RAM و VRAM آزاد، نه فقط ظرفیت اسمی؛
- مجوز استفادهٔ شخصی یا تجاری مدل.

با کوچک‌ترین مدلی شروع کنید که کارتان را قابل قبول انجام می‌دهد. بزرگ‌تر بودن همیشه در برابر زمان، گرما، برق و سرعت ارزش بیشتری ایجاد نمی‌کند.

## خطاهای رایج

- دانلود مدل بسیار بزرگ پیش از یک تست کوچک؛
- فرض اینکه «محلی» یعنی همهٔ افزونه‌ها هم آفلاین‌اند؛
- دادن فایل حساس قبل از بررسی تنظیمات و مجوزها؛
- مقایسهٔ دو مدل با پرامپت‌های متفاوت؛
- پاک‌کردن فایل مدل بدون توجه به محل ذخیره و فضای اشغال‌شده.

## قدم بعدی

یک ابزار را انتخاب کنید، یک مدل کوچک بگیرید و سه کار واقعی اما غیرحساس را با آن بسنجید: خلاصه‌سازی فارسی، استخراج داده در قالب جدول و بازنویسی یک متن. نتیجه را همراه نام دقیق مدل، نسخه، سخت‌افزار و پرامپت ثبت کنید. فقط چنین گزارشی قابل تکرار و قابل اعتماد است.
