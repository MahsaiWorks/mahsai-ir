# ویدیوی اختصاصی متراژ برای سایت

این پروژهٔ Remotion نسخهٔ ۱۲ ثانیه‌ای و بی‌صدای معرفی متراژ را می‌سازد. تصویر کاراکتر فقط برای این ویدیو تولید شده و نماهای داخل گوشی از رابط واقعی نسخهٔ منتشرشدهٔ متراژ هستند.

داستان ویدیو:

- مسئلهٔ آشنا: مشتری پشت خط است و فایل مناسب باید سریع پیدا شود.
- راه‌حل واقعی: نیاز مشتری و فایل‌ها کنار هم دیده می‌شوند.
- پایان روشن: فایل، مشتری و پیگیری روی گوشی و نصب رایگان از کافه‌بازار.

دستورهای اصلی:

```bash
pnpm lint
pnpm render:web
```

خروجی نهایی در `public/videos/metrazh-site-story-v1.mp4` قرار می‌گیرد. فریم ۵۲ برای پوستر صفحه در نظر گرفته شده است.
